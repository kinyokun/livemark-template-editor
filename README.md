# Livemark 模板制作器

网页用于制作模板：安排内容模块、行列、字段、字体和占位元素，保存或导出模板文档。示意文字不代表真实记录，图片使用纯色占位；Live Photo 和移动端手写内容在这里表达位置与样式，实际素材由 App 提供。网页不编辑真实海报、不上传图片、不绘制手写笔迹，也不提供 PNG 导出。

网页和 App 共用 schema 3 模板、字段身份、网格布局、编辑命令和字体依赖。模板在 App 中应用到真实记录后，才生成实际海报。

## 本地运行

在 App 仓库根目录运行：

```sh
node scripts/build_web_editor.js
python3 -m http.server 8874 --bind 127.0.0.1 --directory Web/template-editor
```

打开 `http://127.0.0.1:8874`。构建脚本生成共享模型与布局的 `core.js`，并复制完整字库和 OFL 授权到 `fonts/`。生成文件应通过构建更新。使用 HTTP 本地服务，避免 `file://` 下字体加载、IndexedDB 和 Web Crypto 的浏览器限制。

模板编辑和存储在浏览器本地进行，所需内置字体从本站静态资源加载。模板文件携带已使用的导入字体依赖。

`scripts/publish_web_editor.sh` 会先构建，再将 `Web/template-editor/` 镜像到独立公开仓库。

## 编辑

- 点选元素，单指或鼠标拖动移动；四角缩放，上方圆点旋转。文字左右控制点只改宽度，让正文重新换行。
- 图片、Live Photo 和移动端手写内容使用占位元素，可设置尺寸、位置和样式；实际素材由 App 填入。
- 两指、⌘/Ctrl 加滚轮缩放视口；空白处拖动平移。右键可选择重叠元素；图层列表用于管理前后叠放顺序，并支持锁定与选取。
- Shift 多选，支持组合、解组、对齐、等距分布。方向键微移，Shift 加方向键移动 10pt。⌘/Ctrl Z 撤销，⇧⌘/Ctrl Z 重做，⌘/Ctrl D 复制。
- 内容模块是包含多行多列和合并单元格的容器，可以整体移动、缩放；图层列表以整个模块为一个排序项。进入模块编辑后，点格子添加内容、拖内容换格、拖列边界调宽，Shift 多选格子后合并或拆分。多项内容不能无损合并时会提示先移动内容。
- 画布编辑、模块编辑和导出使用相同布局，进入模块不会撑开空行或移动内容。独立的行列结构面板显示模块的单元格结构，可选择已收起的空格后添加内容；结构面板和画布选框不参与海报排版。
- 模块自动行高随文字增长，空行按设置收起；还可调整行列间距、固定行高，在指定位置插入或删除空行列。模块与其他元素可以“跟随前一项”顺延，图层顺序只控制前后叠放。固定画布溢出会提示，仍可保存和导出模板文件。

## 字段、字体与手写

记录词条包含内置字段和用户自定义词条。自定义绑定存稳定 ID 与显示名称，不按名称偷偷重连。网页导入遇到缺失词条时，保留原有绑定身份和名称，并加入模板字段目录；App 导入时再关联实际的本地词条。

“常规”“长内容”“缺省”三组示意内容用于检查换行、模块高度和空值收起。标记为私人的词条也只使用示意值，网页没有真实记录内容；这些示例不随模板导出。

八款字体包含中文黑体、宋体、文楷、小薇和四款西文。西文使用明确的中文回退链；预览和测量等待字体加载完成。内置字重使用真实静态 400/700 文件，小薇只有 400；导入单文件使用其默认字重。支持导入 TTF/OTF（每个不超过 32MB），文件哈希校验并嵌入模板依赖。字库和许可证来源见 `assets/fonts/poster/manifest.json`（构建后也在 `fonts/manifest.json`）。

移动端手写内容在网页中作为占位设计。实际笔迹在 App 中完成；iOS App 的 PencilKit 可以保留原生笔迹。

图片、Live Photo 和手写占位保留在模板文件中。App 打开模板后提供对应的添加入口，并保留模板设置的框和裁剪样式。海报导出前需要填入仍可见的占位；主动隐藏的占位不阻止导出，保存模板也可以继续保留未填入的占位。

## 保存与交换

草稿与模板库使用 IndexedDB，能够存放完整字体依赖。内置模板保存为独立副本。撤销历史留在内存，当前草稿持久化；浏览器清理站点数据后需要从导出文件恢复。

“导出模板”输出 `.livemark` JSON；App 接收该文件后填入真实内容并导出海报。导入兼容 gzip 包装，schema 1/2 按本次重做约定拒收，保留原文件与 App 原始记录。

## 验证边界

网页模板预览使用 Canvas 2D，App 编辑预览使用原生 Skia，两端共用模板布局规则。相同内容和显示选项下，进入模块编辑不会改变画布几何；空格和隐藏内容通过独立行列结构面板访问。网页占位预览与 App 真实记录的内容不同，不要求画面相同。

源仓库保留共享绘图引擎的验证工具，使用真实 WASM 软件渲染，在 Node/V8 与无窗口 WKWebView 中比较相同输入。这是 App 导出实现的工程验证，不是网页产品功能，不能替代 iOS/Android 真机手势、PencilKit 或内存压力验收。

```sh
node scripts/verify_poster_engine.js
swiftc scripts/render_poster_webkit.swift -o /tmp/livemark-poster-webkit
/tmp/livemark-poster-webkit "$PWD/assets/poster-engine/engine.html" "$PWD/.local/poster-parity/requests.json" "$PWD/.local/poster-parity/webkit"
node scripts/verify_poster_engine.js --compare
```

也可直接比较设备实际导出的两张图片：`node scripts/compare_poster_pngs.js app.png web.png`。它解码 RGBA 后逐像素比较，PNG 压缩方式或元数据不同不会被误判成像素差异。测试产物保存在 `.local/poster-parity/`，不进入发布包。
